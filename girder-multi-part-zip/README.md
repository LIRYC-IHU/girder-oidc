# Girder Multi-Part zip file extraction plugin

A Girder plugin for multi-part zipfile extraction

## Features
- Extract multi-part zip files in a job
- Optional delete of source multi-part zip

## Installation
```bash
pip install -e .
```

## API Endpoint
- `POST /api/v1/zip_tool/extract/{id}` - Extract a multi-part zip file in an Item
